Privacy & Cookies

This static website

This site is a static collection of pages hosted by GitHub Pages. It does not include analytics tags, advertising pixels or embedded social media feeds. The website has no server-side submission endpoint.

Contact form

The contact form checks entered information in your browser and prepares a mailto: draft addressed to TaxiSnaps. The data is not sent to or stored by this static website. Selecting the prepare button may pass the draft content to the visitor’s configured email application. The visitor chooses whether to review, send or discard the draft. Email is then handled by the visitor’s email provider and TaxiSnaps’ own systems.

The form includes an optional marketing-offers preference. Selecting it adds that preference to the email draft; it does not automatically subscribe anyone to a mailing list.

Hosting

GitHub Pages serves the site files. Your browser and hosting provider may process technical information as part of serving and accessing the website. Please refer to the current GitHub privacy information for details.

Cookies

This site does not set cookies using its own code. Hosting or infrastructure providers may use technical mechanisms required to deliver and secure the service; consult the provider’s current information for details.

This page describes the static site, not every separate service or communication channel operated by TaxiSnaps. For questions, contact info@taxisnaps.co.uk.
